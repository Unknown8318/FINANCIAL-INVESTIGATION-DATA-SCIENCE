# Data dictionary

All records and names are fictional. Practice: 5 transfers; independent case: 30 transfers; profiles: 11 accounts. No fraud labels or verified criminal conduct. This is a limited sample.

Fields: transaction_id (unique), timestamp_utc (UTC), source_account (sender), destination_account (receiver), amount_usd (positive whole USD), channel (ACH or Wire), description (unverified memo). Profiles contain account ID, fictional name, business type and limited expected activity. No opening balances, full historical baseline, invoices or beneficial ownership records supplied. Net flow is not balance.
