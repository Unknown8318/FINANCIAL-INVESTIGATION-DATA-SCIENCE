# Week 01: Orientation and Financial Investigation

## Overview
Learn the basic investigation workflow and begin using Python to summarize transactions. Estimated 8–10 hours.

## Objectives
- Explain the difference between an observation, hypothesis and corroborated finding.
- Set up Python and Git; run a script and record its output.
- Understand transaction fields, numeric types and simple screening.
- Develop an independent, reproducible assessment.

## Tasks
1. Install Python 3.11+ and Git if needed. VS Code is optional. Verify versions with `py --version` on Windows or `python3 --version` on macOS/Linux, and `git --version`.
2. Clone using `git clone https://github.com/Unknown8318/FINANCIAL-INVESTIGATION-DATA-SCIENCE.git` and enter the repository directory. If already cloned, use git status and pull only when local work is safe.
3. Read [lesson.md](lesson.md), then run `py modules/week-01/tutorial.py` on Windows or `python3 modules/week-01/tutorial.py` on macOS/Linux. Predict what changes if the sample amount is 5000.
4. Complete [exercises.py](exercises.py), then run it with the same interpreter. All assertions should pass.
5. Read the [case assignment](project.md) and [data dictionary](data/README.md). Write submissions/case_review.py and complete [case report](submissions/case_report.md).
6. Answer the [assessment](assessment.md) in [quiz answers](submissions/quiz_answers.md). Commit and push your own work, then request review.
