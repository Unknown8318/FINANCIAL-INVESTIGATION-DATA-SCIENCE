## Core financial investigation concepts

| Term | Definition |
| --- | --- |
| AML | Anti-money laundering |
| KYC | Know Your Customer |
| CDD | Customer due diligence |
| EDD | Enhanced due diligence |
| SAR | Suspicious Activity Report |
| OSINT | Open-source intelligence |
| Illicit finance | Financial activity connected to unlawful conduct |
| Entity resolution | Determining whether different records represent the same entity |
| Anomaly detection | Identifying unusual behavior within data |
| Transaction monitoring | Reviewing financial activity for potential risk indicators |
| Beneficial ownership | Identifying the people who ultimately own or control an entity |
