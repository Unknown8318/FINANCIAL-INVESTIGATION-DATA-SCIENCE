# Financial Investigation Data Science Development Program (FIDSDP)

A comprehensive, hands-on financial investigation data science development program covering Python, AML, fraud detection, financial intelligence, machine learning, and blockchain analysis.

Start with [Week 01](modules/week-01/README.md), review the [syllabus](SYLLABUS.md), and track [progress](PROGRESS.md).

| Week | Module | Project | Status |
|---|---|---|---|
| [01](modules/week-01/README.md) | Orientation and financial investigation | Initial transaction review | Ready |
| 02 | Python fundamentals | Transaction summaries | Planned |
| 03 | Advanced Python and pandas | Data cleaning pipeline | Planned |
| 04 | Exploratory data analysis | Transaction dashboard | Planned |
| 05 | Fraud classification | Validated fraud classifier | Planned |
| 06 | Statistics and regression | Financial behavior analysis | Planned |
| 07 | Feature engineering and ensembles | Risk scoring | Planned |
| 08 | Anomaly detection | Unusual activity detection | Planned |
| 09 | Network and graph analytics | Financial relationship mapping | Planned |
| 10 | Cryptocurrency investigation | Public ledger analysis | Planned |
| 11 | APIs and automation | Data collection pipeline | Planned |
| 12 | SQL and deployment | Financial intelligence database | Planned |
| 13 | Capstone investigation | Operation Paper Trail | Planned |

Week 01 is available; subsequent modules are planned, not yet authored. Work at your own pace. All case data are synthetic; never publish private records or credentials. Indicators are leads, not evidence of criminality. This is a self-study portfolio, not an accredited certification.
